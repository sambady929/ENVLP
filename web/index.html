Getting started

    
    
      
  1. Pick a part in the palette (left), then click the canvas to
        place it. Space rotates the ghost,
        Shift+Space flips it, Esc cancels.
    2. 
      
  2. Wire (W): click to start, click the destination —
        a pin or any grid point. Space while wiring swaps the route
        between horizontal-first and vertical-first, Enter ends the
        wire and Esc cancels. Moving a part drags the wires
        attached to its pins; a wire segment can be dragged on its own.
    3. 
      
  3. Net labels (N): type space-separated names
        (out in), then click each net. Click a label to select
        it and press Del to remove it.
    4. 
      
  4. Place at least one GND symbol.
    5. 
      
  5. Choose an analysis on the right, fill in the fields it asks
        for, and press Run analysis (Ctrl+Enter).
    6. 
      
  6. Read the typeset Math and the Report on the left, the
        Plot on the right.
    7. 
    

    
Drag the thin dividers between the panels to resize them.
      A part's model parameters (gm, ro, Cgs and the passives'
      parasitics) are in the properties panel on the right — click the part
      first.

What each analysis does

    

      
Transfer function H(s)

      
the small-signal gain V(out)/V(in). Reports the DC gain, the pole/zero
        corner frequencies and the dominant time constant.


      
AC (small-signal)

      
drives every independent source and superposes the responses, so
        there is no in field.


      
DC operating point

      
the large-signal bias: node voltages and each device's Id/Vdsat.
        The model, the supply rail and the thresholds are set in the
        operating point section below the analysis options.


      
PSR / PSRR

      
ripple on the supply rail referred to the output.


      
Loop gain (return ratio)

      
Rosenstark return ratio: name the amplifier in ref. amplifier
        — the part whose gain is set to zero to break the loop.


      
Short-circuit current

      
the output current into a short.


      
Input impedance / Output impedance

      
Zin at the input port; Zout with every source turned off (the
        output-impedance analysis has no in field).


      
Noise

      
output and input-referred noise density, integrated over the sweep
        band, with a per-source contribution breakdown.


      
Differential (Adm/Acm/CMRR)

      
a differential drive (in+ / in−) and a differential
        output, given as a port such as V(a)-V(b).

    

    
ignore negligible terms drops terms far below the
      dominant one, so the result stays readable — the low-entropy form.
